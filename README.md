# RestaurantOS

Read START_HERE.md before running this version. Existing RestaurantOS accounts and data use the main connection; signed demo visitors use a separate connection/schema. Do not seed or reset an existing database.

Run `npm ci` and `npm run dev` from the configured local ready folder. The distributable ZIP excludes private credentials.

FINAL_VERIFICATION.md records the executed tests and the remaining build/browser verification limitations.
